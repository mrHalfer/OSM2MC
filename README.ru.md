# tMC — экспортёр карт в Minecraft

[English](README.md) · **Русский**

tMC превращает картографические данные в мир Minecraft Java Edition (zip-сохранение): здания с этажами, окнами, интерьерами и крышами, дороги с разметкой и зеброй, железные дороги, воду, леса, парки, поля, рельеф, пещеры, деревни и несколько скрытых структур (стронгхолд, Древний город, лес скрипунов …).
Это самостоятельная программа для Windows (Qt 5.15.2 / MSVC, qmake, GDAL).

Источник данных — один из вариантов:

- выгрузка **OpenStreetMap** (`.osm`, `.pbf`, `.osm.pbf`) — или область, которую вы обводите на встроенной онлайн-карте, а tMC скачивает её сам;
- файл проекта **`.tqt`** (слои `Shape=`, `Rastr=`, `Wkt`, `SpatialFilter`, настройки 3D `Wdf3D=`);
- **папка с shape-файлами** (все `*.shp` и матрицы высот `*.tif/*.tiff` в самой папке; рядом с каждым shape нужен `.prj`).

## Быстрый старт (окно)

1. Запустите `tMC.exe`. Справа — онлайн-карта OpenStreetMap. Найдите место в строке поиска, нажмите **Граница** и обведите многоугольник области экспорта (до **25 км²**; площадь показана на карте). По желанию отметьте точку спавна и церкви для входов в стронгхолд / Древний город / лес скрипунов.
2. Нажмите **Скачать область** — данные загрузятся с серверов OpenStreetMap (Overpass API) и откроются как локальный файл. (Вместо этого можно ввести путь к OSM-файлу или выбрать его кнопкой в поле *Файл OSM* слева; если очистить поле, вернётся онлайн-карта.)
3. Выберите параметры мира слева (версия, что вне области, сид, пещеры, климат) и нажмите **Экспорт**. Результат — `<имя файла>.zip` рядом с OSM-файлом; распакуйте его в `.minecraft/saves` (или положите туда как есть).

**Файлы проекта.** Кнопки *Сохранить проект…* и *Открыть проект…* в левом верхнем углу сохраняют и восстанавливают работу в файле `.tmc` (JSON): положение карты, границу, отметки спавна и входов (в долготе/широте, не зависят от проекции данных), файл OSM, если данные загружены из него, и параметры мира. `tMC project.tmc` открывает его сразу при запуске.

После завершения экспорта в окне с результатом есть флажок *Показать файл в папке* (откроется Проводник с выделенным архивом).

Работа с сетью следует правилам OpenStreetMap: тайлы карты кэшируются на диске, поиск идёт в Nominatim не чаще раза в секунду, программа представляется заголовком `User-Agent`, на карте есть подпись «© участники OpenStreetMap». Не злоупотребляйте публичными серверами.

### Язык интерфейса

Интерфейс есть на **английском** и **русском**. По умолчанию язык берётся из системы (любой, кроме русского, — английский). Переключатель **Язык** в правом верхнем углу окна меняет его сразу, без перезапуска; ключ `--lang auto|en|ru` задаёт язык на один запуск без сохранения. Экспортируемые миры от языка интерфейса не зависят.

## Командная строка

```
tMC [источник] [-o|--out мир.zip] [--format 26|1.21] [--flat] [--seed N] [--caves 0|1]
    [--climate auto|temperate|boreal|tundra|steppe|mediterranean|desert|savanna|tropical]
    [--clip "lon lat; lon lat; ..."] [--spawn-lonlat "lon lat"]
    [--stronghold "x z"] [--city "x z"] [--pale "x z"] [--no-locate-datapack]
    [--osm-rules правила.json] [--osm-ini osmconf.ini] [--no-greenery] [--enhancer файл.dat | --no-enhancer]
    [--t3d файл.t3d] [--real-meters 0|1] [--dry-run] [--download-osm "lon lat; ..."]
    [--lang auto|en|ru] [--theme auto|light|dark] [--debug] [--log журнал.txt] [--nogui]
```

Полный список — `tMC --help`. Замечания:

- `источник` — файл `.tqt`, выгрузка OSM или папка (по умолчанию — текущая папка). Без аргументов открывается окно.
- `--nogui` — экспорт без окна, код выхода 0 при успехе. Программа оконная, поэтому при перенаправлении вывода консоль может молчать — используйте `--log`.
- `--clip` ограничивает экспорт многоугольником (WGS84): экспортируется только то, что внутри, чанки снаружи не записываются.
- `--download-osm "lon lat; …" -o область.osm` скачивает область (до 25 км²) и завершается.
- `--dry-run` — только загрузка и классификация (сводка «код × число объектов» в журнале); удобно подбирать правила OSM.
- Настройки 3D выбираются по порядку: `--t3d` → любой `.t3d` в папке с shape-файлами → `Wdf3D=` проекта `.tqt` → `default.t3d` рядом с exe.
- **Датапак для поиска структур** (по умолчанию включён; `--no-locate-datapack` отключает) добавляет наборы структур, чтобы `/locate` и глаз Эндера находили стронгхолд, Древний город, пещеры испытаний и руины порталов. Сами структуры записаны в чанки и от датапака не зависят. Минус: при открытии такого мира игра предупреждает об экспериментальных функциях.
- Пример: `tMC город.osm.pbf --osm-rules osm_rules.json --nogui --log run.log`.

## Правила OpenStreetMap

Объекты читает драйвер OSM из GDAL; затем правила из **`osm_rules.json`** раскладывают их по виртуальным «слоям tqt» (`osm.bldpol`, `osm.vegpol`, `osm.rdslin` …) и задают поля `CODE` (тип объекта), `REL` (высота), `MAT` (материал) и т. д. Дальше всё работает так же, как с shape-файлами и настройками 3D (`default.t3d`). Формат правил описан в разделе `_help` самого файла; файл правится вручную, без пересборки.

- Файл правил ищется по порядку: `--osm-rules` → рядом с OSM-файлом → рядом с exe → в текущей папке.
- Условия: значение, `"*"` (тег есть), `"-"` (тега нет), `"!v"` (тег есть и не равен), списки, регулярные выражения `"~re"`, числа `">=4"`; служебные теги `poi:<тег>` (точки внутри контура здания), `area:<тег>` (охватывающие участки), `_area`, `_perim`. Шаблоны: `{тег}`, `{тег1,тег2}`, `{тег|num}`, `{тег|num*3}`, варианты через `||`.
- **Два прохода.** Правила с `"pass": 2` видят только здания, которые не опознал 1-й проход, и используют теги о ближайших опознанных зданиях (`nb:code`, `nb:share`, `nb:n`, `nb:rel`, `nb:dist`).
- **Высота** (`"REL": "auto"`): тег `height` → `building:levels` по формулам пересчёта этажей → типовая высота по коду из `heights.csv` → 6 м. **Материал** (`MAT`) берётся из `building:material` / `building:facade:material` (кирпич, камень, дерево, стекло, металл, бетон, панели …).
- **Адреса** (`osm/tmcaddress.cpp`): тип улицы, название и номер дома для табличек на домах и указателей на перекрёстках разбираются из `addr:*` и `name` автоматически (русские типы улиц распознаются; для других языков название берётся целиком).
- **Растительность**: дворы между домами, тайга в частном секторе, леса до доли площади, парки, «дикие» леса с лагерями разбойников на больших пустых участках; настраивается блоком `greenery` в правилах, `--no-greenery` отключает.
- **Климат**: биомы, поверхность и породы деревьев области экспорта зависят от климатической зоны — она определяется по координатам или задаётся вручную (`--climate`, список *Климат*).
- **Улучшайзер** (`tmc_buildings.dat`) — файл точек зданий (тип, высота, этажность), используется только когда OSM их не даёт; приоритета над OSM нет. Высоты и этажность в нём намеренно «зашумлены», это приблизительные значения, а не точные данные. Без файла всё работает (`--no-enhancer`).
- Отладка: `TMC_OSM_DEBUG=1` — в журнал по строке на здание (какие теги увидели правила, какой слой и код получились); `TMC_OSM_UNMATCHED=файл.tsv` вместе с `--dry-run` — счётчики объектов, которые не покрыло ни одно правило.
- Не поддерживаются: точечные объекты (знаки, остановки, светофоры) и отношения, кроме multipolygon.

## Что есть в мире

Кроме экспортируемых объектов, в мире есть: пещеры под землёй (из шаблонов настоящего игрового мира), лес скрипунов с особняком, аванпосты и лагеря разбойников, кораблекрушения в больших водоёмах, руины порталов в лесах, парящие острова над парками, деревни из скоплений частных домов, подземелья церквей с секретными ходами в стронгхолд и Древний город, подземные лаборатории научных зданий с механизмами на красном камне, мебель, жители, манекены и сундуки с ванильным лутом. Шаблоны структур — `resources/templates/*.bin`; без шаблона соответствующая функция пропускается или упрощается (причина пишется в итоговой строке журнала).

## Сборка

Нужны Qt 5.15.2 (MSVC) и Visual Studio с MSVC x64. Заголовки GDAL и библиотека импорта `gdal_i.lib` (GDAL 3.4) лежат в `third_party/gdal`, поэтому для сборки больше ничего не нужно. Для ЗАПУСКА нужен рантайм GDAL 3.4 (`gdal304.dll`, его зависимости и папки `gdal-data`, `projlib`, `gdalplugins`, около 83 МБ): скачайте `gdal-runtime-3.4.zip` из релизов и распакуйте в `third_party/gdal/bin` (см. `third_party/gdal/README.md`). После каждой сборки он сам копируется рядом с `tMC.exe`, так что программа запускается прямо из Qt Creator.

**Новый компьютер, коротко:** установите Qt 5.15.2 (комплект MSVC 2019 64-bit), Visual Studio или Build Tools (нагрузка «Разработка классических приложений на C++») и, для тестов, Python 3 → клонируйте репозиторий → запустите `setup.bat` (он проверит инструменты и скачает рантайм GDAL в `third_party/gdal/bin`) → откройте `tMC.pro` в Qt Creator и нажмите Run (или запустите `build.bat`). `build.bat` сам находит Visual Studio (vswhere) и Qt (`C:\Qt\5.15.2\msvc2019_64` или `qmake` из `PATH`).
`build.bat` — теневая сборка (`qmake` + `nmake release`) в каталоге `%TMC_BUILD%` (по умолчанию `Builds\tMC` рядом с папкой `Projects`); результат — `%TMC_BUILD%\release\tMC.exe`, лог — `build_nmake.log`.
Пути настраиваются переменными окружения `VCVARS` (vcvarsall.bat), `QTDIR` (по умолчанию `C:\Qt\5.15.2\msvc2019_64`), `GDAL_DIR` (необязательно: другой GDAL; по умолчанию берутся заголовки и `gdal_i.lib` из `third_party/gdal`), `TMC_BUILD`.
После линковки `tMC.pro` копирует рядом с exe всё из `resources/`. Если exe запущен, линковка падает (LNK1104) — закройте программу. Новые файлы добавляйте в `tMC.pro`.

Русский перевод интерфейса — `translations/tmc_ru.ts` (встраивается в exe через `lrelease`); после изменения строк обновите его: `lupdate tMC.pro -ts translations/tmc_ru.ts`. Исходные строки в коде — английские.

## Подготовка релиза

`make_release.bat` готовит пакет, который запускается из коробки, одним действием: собирает программу, запускает `windeployqt` (Qt DLL и плагины), добавляет среду выполнения Visual C++ (рядом с exe), рантайм GDAL из `third_party/gdal/bin`, шаблоны структур `*.bin`, `default.t3d`, `osm_rules.json`, `heights.csv`, `tmc_buildings.dat`, README и `THIRD_PARTY_NOTICES.md` (и `LICENSE`, когда он появится),
затем **запускает результат с чистым `PATH`** (без Qt и без GDAL), чтобы убедиться, что он работает сам по себе, и упаковывает в `Builds/tMC/package/tMC-<версия>-win64.zip` (версия — строка `VERSION` в `tMC.pro`). Пользователю достаточно распаковать zip и запустить `tMC.exe`, ничего ставить не нужно.
`third_party/gdal/make_runtime_zip.bat` делает `gdal-runtime-3.4.zip` (содержимое `third_party/gdal/bin`) для страницы релизов: именно его скачивает `setup.bat` (адрес задаётся в `setup.bat` или переменной `GDAL_RUNTIME_URL`).
Не входят в релиз: `tests/`, `docs/`, исходники.

## Тесты

Тесты, стенд C++ экспортёра, серверы Minecraft (26.3 и 1.21.11) и генерация тестовых миров лежат в `tests/` — см. `tests/README.ru.md`.
Быстрая проверка (OSM-классификация и режим «папка»): `py -3 tests\run_tests.py`. Полный прогон со стендом и серверами: `py -3 tests\run_tests.py all`.

## Устройство

| Папка | Назначение |
|---|---|
| `app/` | `main.cpp` (командная строка), `mainwindow.*` и `mainwindow.ui` (окно; вёрстка правится в Qt Designer), `mappreview.*` (предпросмотр загруженных данных), `osmtilemap.*` и `osmonlinepanel.*` (онлайн-карта, поиск, граница, загрузка), `httpclient.*` (клиент на WinHTTP), `osmdownload.*` (загрузка через Overpass), `i18n.*` (язык интерфейса), `theme.*` + `resources/tmc.qss` (светлая/тёмная тема), `tmcrun.*` (полный цикл экспорта, общий для окна и командной строки) |
| `input/` | `tmcproject.*` — загрузка `.tqt`, папки shape-файлов и выгрузки OSM через OGR, перепроекция; `t3dsettings.*` — разбор `.t3d` |
| `osm/` | `tmcosmrules.*` — правила «теги OSM → слой/код»; `tmcenhancer.*` — улучшайзер зданий; `tmcrel.*` — высоты зданий; `tmcaddress.*` — адреса; `tmcgreen.cpp` — достройка растительности |
| `scene/` | `mcscene.*` — сбор объектов экспорта по слоям; `modelbuilder.*` — построитель мешей объектов |
| `export/` | экспортёр мира Minecraft (воксели, чанки, NBT, zip), климатические зоны (`climate.h`) |
| `core/` | базовые классы: `MapFeature`, `MapLayer`, `HeightRaster`, геодезические помощники |
| `resources/` | иконка, `default.t3d`, `osm_rules.json`, `heights.csv`, `tmc_buildings.dat`, шаблоны `templates/*.bin` |
| `translations/` | файлы переводов Qt |
| `tests/`, `docs/` | скрипты разработчика, тесты, рабочие заметки |

CRS проекта: строка `Wkt` из `.tqt`, иначе `.prj` первого слоя; для данных WGS84 — EPSG:3395 (или `DefaultCrs=` из `tMC.ini`/`TQT.ini` рядом с exe).
